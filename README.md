# Anat&Phys Illustration Club

A student portfolio combining art, biology, anatomy, and physiology.

The website includes themed anatomy illustrations, explanations of body-part functions, member names, and links to the club interest form and Instagram. The current artwork is labeled as AI-generated concept illustrations.

## Publishing

Serve this repository through GitHub Pages from the main branch and repository root. No build step is needed.

## Editing

- `index.html`: page content and member names
- `styles.css`: visual design and responsive layout
- `script.js`: mobile navigation and gallery filters
- `assets/`: illustrations
